# IA YAYA — V1

Web estática bilingüe ES/EN para publicar en GitHub Pages.

## Publicación
1. Crea un repositorio público en GitHub (por ejemplo `ia-yaya`).
2. Sube `index.html` y la carpeta `assets`.
3. En Settings → Pages, selecciona `Deploy from a branch` y `main` / root.
4. La URL resultante será el destino permanente del QR.

La V1 contiene un formulario de demostración: no envía datos todavía. La URL puede mantenerse durante la evaluación y actualizarse posteriormente.
